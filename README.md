# Vriddhi 2026 — NIT Rourkela Annual Sports Fest

A React/Vite recreation of the public-facing Vriddhi 2026 website, based on the live site's visual structure and publicly visible content.

## Live website

https://www.vriddhi.co/

## Tech stack

- React
- Vite
- CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Note

This repository is a clean recreation and does not claim to contain the original private source code or original proprietary assets.
